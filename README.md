# Arnest Muthiani Portfolio v2

Multi-page responsive portfolio built with HTML, CSS and vanilla JavaScript.

Pages: Home, About, Experience, Skills, Project, Education and Contact.

## Run
Open `index.html` in a browser.

## Customize
- Replace the portrait placeholder on the home page with your photo.
- Replace the three image placeholders on `project.html` with Anilov screenshots.
- Contact information and Anilov's live URL are already included.

## Netlify
Publish directory: project root.
Build command: leave blank.
No build step is required.
